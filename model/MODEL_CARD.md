# Traceline model card (Workstream B)

> **All numbers below are generated by `python -m traceline_model.model_card` from `reports/*.json` and are measured on SYNTHETIC stand-in data (development split). They are not hidden-set results and not real-hardware results. Member C re-scores the headline numbers independently.**

## Intended use
A positioning engine for a simulation and planning prototype: robust 2-D position, uncertainty, per-anchor blocked-reading probability, short motion forecast and a traceable explanation. Not a certified life-safety system.

## Model
- Per-anchor shared encoder, per-anchor NLOS / reliability / bias heads, differentiable closed-form weighted multilateration, GRUCell (hidden 64) for temporal fusion, heads for correction, sigma and a 10-step forecast.
- ONNX opset 17, 159 KB. Inputs: 8 anchor slots (x, y, range, rssi, valid_flag, crowd), previous position + validity, dt, recurrent state. Normalisation is train-only and lives in the graph.
- State: shape [1, 64]; reset = At the start of every run set state to zeros and previous_position_valid to 0.
- Crowd input enabled: **False** (contract: optional, only if the team agrees).
- Uncertainty semantics: sigma_m is the per-axis standard deviation of an isotropic 2-D Gaussian trained with Gaussian NLL. Radial error is then roughly Rayleigh(sigma); nominal P(error <= k*sigma) = 1-exp(-k^2/2). It is only as good as the calibration reported in MODEL_CARD.md.
- `confidence` = confidence = 1 / (1 + sigma_m). A monotone transform of sigma, NOT a probability.

## Data
Generated by `traceline_model/standin_data.py` from the guide's section 8 equations (range noise 0.15+0.02d, RSSI path loss with 2.5 dB noise, NLOS bias U(0.5,3.0) m, 5%+ packet loss, outages, outliers, drift, crowd effects). Venues: hospital, warehouse, office sketches (clinic is hidden-only and never built). **Temporary**: replace with Member A's datasets (same CSV contracts). Splits are by whole run; seeds 1000 (train) / 2000 (dev).
Dev set: 24 runs, 7380 steps.

## Limitations and failure modes
- Synthetic data only; real radio behaviour (multipath, body shadowing, antenna patterns) is not modelled. A pilot is the next step.
- Accuracy falls sharply with only 3 active anchors and with few valid anchors (see slices); the model cannot invent missing geometry.
- Heavy NLOS (more than about half of readings blocked) limits every method; stand-in hospital layouts are deliberately harsh.
- sigma is a learned estimate; use the calibration plot before treating it as a probability region.
- Dead-reckoning during long outages drifts; the forecast head only extends 10 steps (5 s).
- The optional crowd input is a proxy in this stand-in data (computed from jittered truth); do not trust crowd-benefit claims until A's crowd data and a deployment-faithful input exist.
- The clinic venue was never seen and never evaluated here; Member C scores it once after the freeze.
